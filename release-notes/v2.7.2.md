# Restate Operator v2.7.2 Release Notes

## Highlights

- **Security: distrust the compromised eMudhra intermediates** - Eight eMudhra
  intermediate CA keys were compromised. This release rejects any TLS chain that
  contains them, including chains cross-signed by another root. This is a
  backport of the dependency bumps in
  [#222](https://github.com/restatedev/restate-operator/pull/222) for clusters
  still on the 2.7 line.

## Security Fixes

| Crate | From | To | Advisories |
|---|---|---|---|
| `rustls-webpki` | 0.103.13 | 0.103.16 | RUSTSEC-2026-0382 |
| `webpki-roots` | 1.0.6 | 1.0.10 | RUSTSEC-2026-0381 |
| `rustls` | 0.23.37 | 0.23.46 | RUSTSEC-2026-0285, 0346, 0348, 0349 |
| `h2` | 0.4.13 | 0.4.20 | RUSTSEC-2026-0258 |
| `anyhow` | 1.0.102 | 1.0.104 | RUSTSEC-2026-0190 |

`rustls-webpki` 0.103.16 rejects every certificate path that contains one of
the eight compromised intermediates, whichever root it chains to.
`webpki-roots` 1.0.10 removes the emSign ECC Root CA - G3.

**Impact on Users:**
- The operator rejects TLS peers that present a certificate issued by one of
  the compromised intermediates.
- No behaviour changes otherwise.

**Migration Guidance:**
No configuration changes are required.

---

## Upgrading

No CRD changes in this release. Upgrade the operator via Helm:

```bash
helm upgrade restate-operator oci://ghcr.io/restatedev/restate-operator-helm \
  --namespace restate-operator \
  --version 2.7.2
```
